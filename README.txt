How to play:

Move - WASD
Look - Mouse
Jump/Double jump - Spacebar
Slide - Left Shift
Forward punch - Left click
Uppercut - Right click

After finishing a level and viewing stats:

Next level - Right arrow
Retry level - Left arrow

Restart Game - R key

Quit - ESC
